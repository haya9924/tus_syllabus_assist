# TUS Assist（CLASS + LETUS）

東京理科大学の2つの教育システムを、1つにまとめた Chrome 拡張機能です。

| システム | URL | できること |
|---|---|---|
| **CLASS** | `class.admin.tus.ac.jp` | シラバスの保存・比較、履修時間割、成績スコアとリンク、CLASS 上のサイドバーパネル |
| **LETUS** | `letus.ed.tus.ac.jp` | トップページの改造（交換・並べ替え・非表示・配色）、課題の To Do 連携、提出完了のパチンコ演出、実績（XP／レベル） |

- インストールは **1回だけ**。CLASS のデータ（履修・成績）と LETUS のデータ（実績・設定）は別キーで `chrome.storage.local` に保存され、互いに干渉しません
- **To Do 連携に必要な権限（認証・各サービスへの通信）はオプション権限**です。許可しなくても他の機能はすべて動きます
- **ダークモード**を CLASS・LETUS・拡張の各画面に用意しています（時刻指定 / 日の出〜日の入り / OS 設定）

## インストール

### 方法1: Releases から CRX をダウンロード（推奨）

1. GitHub の **Releases** ページ（[https://github.com/haya9924/tus_syllabus_assist/releases](https://github.com/haya9924/tus_syllabus_assist/releases)）を開く
2. 最新のリリースの **Assets** 欄から **`tus_syllabus_assist.crx`** をダウンロード
3. Chrome アドレスバーに `chrome://extensions/` を入力して開く
4. 右上の **「デベロッパーモード」** を **ON** にする
5. ダウンロードした **`.crx` を chrome://extensions/ のページ上へドラッグ＆ドロップ**
6. 確認ダイアログの **「拡張機能を追加」** をクリック

> Chrome Web Store 経由ではないため、起動時に「この拡張機能を削除しますか？」の確認が出ることがあります。「キャンセル」で使い続けられます。

### 方法2: ソースから読み込む（開発者向け）

1. このリポジトリを `git clone` する（または ZIP を展開）
2. `chrome://extensions/` を開き、右上の「デベロッパーモード」を ON
3. 「パッケージ化されていない拡張機能を読み込む」 → リポジトリのフォルダ（`manifest.json` がある階層）を選択

> プライバシー: `*.pem`（署名キー）と `*.crx`（パッケージ）は `.gitignore` で除外され、リポジトリには含まれません。
> 署名キーは拡張機能IDの生成に使うため**第三者に渡さないでください**。`.pem` を維持すれば拡張機能IDが変わらず、
> 保存済みデータと更新導線をそのまま継続できます。

## CLASS：シラバス比較・時間割・成績リンク

### CLASS の機能

1. **「+ 追加」ボタン** — シラバス拡大ダイアログに表示（一覧画面からは不完全な情報しか取れないため、一覧の行への追加ボタンは無し。追加は詳細画面からのみ）
2. **ツールバーのポップアップ** — アイコンクリックで CLASS の保存件数・履修予定・単位数と LETUS の実績（Lv／XP／連続提出）をまとめて表示。「CLASS ダッシュボード」「LETUS 設定」ボタンから各ページを開く
   - **ダッシュボード**（CLASS）:
   - **シラバス比較タブ**: 保存した授業を2つ以上選択して項目別横並び比較（スコア表示・スコア降順ソート対応）
   - **時間割表タブ**: 月〜土 × 1〜8限のグリッドに自動配置（重複検出、手動メモ対応）。履修予定の**合計単位数**を表示。各コマに講座メモ・成績スコアも表示
- **講座メモ**: 各カードの「メモ」ボタンで自由文を保存。比較・時間割・成績タブと詳細モーダルに表示
- **講座の色付け**: 各カードの「色」ボタンで色を保存（パレット＋カスタム色・クリア可）。比較・時間割・成績タブにドット表示し、時間割のコマ・各カードの背景色も講座色で薄く染めて区別しやすくする。**色を指定していない科目は白背景（グレーの左ボーダーのみ）**で表示。編集は比較・成績タブから
- **右側サイドバー**（CLASS上）：縮小タブで常駐し、クリックで展開。ミニ時間割（履修予定）＋追加講座一覧（履修予定のみ切替可）。右上「«」で縮小、「×」で非表示（ポップアップから再表示）。状態は保存され複数タブで同期。パネルの幅・文字サイズは設定タブから変更可（保存すると即時反映）
   - **成績リンクタブ**: 保存済み授業を全件表示 → 各授業の「成績を接続」から成績照会の候補一覧を選んでリンク／解除
   - **設定タブ**: スコア重み設定、JSON エクスポート/インポート、全データ削除
3. **成績一覧の行ボタン** — 成績評価公開授業照会の各行に、保存済み授業があれば「成績をリンク」、無ければ「＋成績追加」（成績リンク用のみ保存。シラバス比較には追加しない）。成績ページで開いた詳細ダイアログには追加ボタンを出さない
4. **成績スコア（5〜0点）** — 成績分布から `S×5＋A×4＋B×3＋C×2＋D×0 ÷ 100` で算出。成績評価状況の横にスコア列を追加し、検索結果をスコア降順に並べ替え可能（表示中ページ内）
5. **バッジ表示** — ツールバーアイコンに保存件数を表示

### CLASS の使い方

### はじめての方へ：基本的な使い方（シラバス照会 → 成績評価公開授業照会）

基本の流れは **「シラバス照会で科目を登録」→「成績評価公開授業照会で成績をリンク」** です。ページ上のボタンは科目ごとの状態に合わせて自動で切り替わり、初心者でもボタンを見てクリックするだけで進められます。

**① シラバス照会で科目を登録する**
1. 検索結果の科目名リンクをクリック → シラバス照会ダイアログが開く
2. 右上（ふせん/印刷ボタンの横）の **「+ 追加」** をクリック
   - シラバスの**全項目（概要・目的・成績評価方法・教科書・授業計画など）**が保存され、**「追加済み✓」** に変わります
   - この時点で拡張機能のダッシュボードに登録され、比較・時間割に使える状態になります

**② 成績評価公開授業照会を開いて成績をリンクする**
1. 成績評価公開授業照会を開いて検索する（いつもの成績の表）
2. **①で登録した科目の行に「成績をリンク」ボタン** が出ているので、それをクリック
   - 保存済み授業を選ぶ**候補一覧の画面**が開きます
3. 候補一覧から該当の授業を選ぶと、その行の **成績分布（S/A/B/C/D）とスコア** がリンクされ、ボタンが **「成績リンク済」** に変わります
   - 「成績リンク済」をクリックするとリンク先の変更・数値の編集もできます
   - これで **成績データとシラバスが1つの授業としてまとまり**、ダッシュボードの比較・時間割・成績リンクタブすべてに反映されます

**③ ダッシュボードで確認する**
- ツールバーの拡張機能アイコン →「ダッシュボードを開く」→ **成績リンクタブ**
- リンク済みの授業一覧・成績分布・スコアを確認でき、**「成績を接続」** でリンク／解除もできます
- シラバス比較タブ・時間割表タブにも登録した授業が並びます

**逆の順序（成績を先に保存しておきたい場合）**
- 成績評価公開授業照会で **「＋成績追加」** をクリックすると、その行の成績データだけを先に保存できます（ボタンは「成績保存済み」に変化。未接続のものはページ下部の「保存した成績データ（未接続）」にも並びます）
- 後からシラバス照会で同じ科目の **「+ 追加」** を押すと、シラバス保存と同時に**未接続の保存成績と自動リンク**も完了します（「追加済み✓」）
- どちらの順番で進めても、最終的には成績とシラバスを1つにまとめられます

### シラバス詳細から追加（唯一の追加経路）
一覧画面の行からは完全なシラバスが取れないため、一覧の行に「+ 追加」ボタンは出しません。追加はシラバス詳細画面からのみ行います（ダイアログには追加ボタンと、一致時のみ現れるリンクボタンの最大2つを表示）。
1. 検索結果で科目名リンクをクリック → シラバス照会ダイアログが開く
2. 右上（ふせん/印刷ボタンの横）の **「+ 追加」** をクリック
   - 全項目（概要・目的・到達目標・成績評価方法・教科書・授業計画・備考・BYOD等）を保存
   - 未接続の保存成績（「＋成績追加」で保存した行）があれば**同時にリンク**し、ボタン一発で「追加済み✓」まで完了します
   - 別科目を開き直してもボタンが追従（AJAX再描画対応）
   - 旧データで成績分布側だけ追加済みの場合もボタンは **「+ 追加」** のまま有効化され、押下で詳細保存＋リンクが同時に完了します

### 片側だけ追加済みの場合の小さめ注意表示
授業コードで成績分布側とシラバス側の同一性を確認し、保存済みでも当該側が未完了の場合は行内にボタンより一回り小さいアンバー文字の注意書きを出します（追加ボタンは出しません）。「＋成績追加」の明示保存（授業なし）も成績側の登録とみなします。
- 成績照会の行 → 「シラバス側ですでに追加されています」（リンク完了で消去）
- シラバス照会の行 → 「成績分布側ですでに追加されています」（詳細追加で消去）。一覧の注意書きは文字表示のみです
- シラバス詳細ダイアログ内にも同文言を表示。未接続の保存成績と授業コードが一致する場合のみ **「成績をリンク」ボタン** も併置し、押すと成績データ候補モーダル（分布・スコア付き）が開き、候補選択でシラバス詳細の全項目保存と同時にその候補をリンクします
- 一覧の描画タイミング取りこぼしに備え、定期再スキャン＋別タブの変更検知でも再表示します

### データの主従関係
- **基本はシラバス照会のデータ**：比較タブ・時間割タブ・サイドバーにはシラバス詳細まで取り込んだ講座のみ表示
- **成績側はあくまで補助**：成績分布・スコアのみ。成績のみのデータは成績リンクタブでのみ表示（「詳細未取得」バッジ付き）

### 成績分布の手動リンク（ダッシュボード起点）
1. ダッシュボードの **成績リンクタブ** に保存済み授業が全件表示される
2. 各授業の **「成績を接続」** → 成績照会の候補一覧（スコア降順・絞り込み可）から **「この成績にリンク」**
   - 候補は成績評価公開授業照会で検索を実行すると自動収集される
   - 接続済みは **「接続解除」**／接続先変更／数値の直接編集が可能
3. 成績照会の各行の **「成績をリンク」** ボタンから保存済み授業を選ぶ従来フローも利用可
4. 成績一覧で **「＋成績追加」** を押した行は、下の「保存した成績データ（未接続）」に並ぶ。ここから保存済み授業への紐付け・削除ができる（シラバス比較には追加されない）

### 成績スコアと並べ替え
- スコア = (S×5＋A×4＋B×3＋C×2＋D×0) ÷ 100（最大5.0〜最小0.0、重みは設定タブで変更可）
- 成績照会の表に **スコア列** を成績評価状況の横（D評価の右）に追加。**スコア列ヘッダーのクリック**または表上の「スコア降順に並べ替え」で表示中ページ内を高い順にソート（ヘッダー再クリック／「元の順序に戻す」で復元）
- ダッシュボードの比較タブでもスコア表示・スコア降順ソート、比較表に「成績スコア」行を追加

### ダッシュボード
- ツールバーアイコン → ポップアップ → 「ダッシュボードを開く」
- **すべての講座パネル**（比較・時間割・成績タブ）に **「詳細」ボタン** を配置。クリックするとシラバス詳細（概要・評価方法・授業計画など全項目）が開き、その中に **成績分布のヒストグラム**（S/A/B/C/Dの棒グラフ＋スコア）と **編集ボタン（成績・メモ・色）** も表示されます（成績の編集はこの詳細画面から行います）
- **シラバス比較**: カードのチェックで複数選択 → 「選択した授業を比較」→ 項目別横並び表示（相違は黄色ハイライト）+ 同時限の警告。**成績分布は単一グラフ（S/A/B/C/Dの各判定に講座ごとの系列バーを並べた形式）で視覚比較**できる（凡例付き・数値も併記）
- **時間割表**: カードの「履修予定に追加」で曜日時限に従い自動配置。重複コマは赤色。空きセルダブルクリックでメモ追加。追加リストの候補にも成績スコアを表示。**追加候補カードからもメモ・色を編集可**（保存するとコマ表示にも反映）
- **成績リンク**: 保存済み全件表示 → 接続／接続解除／直接編集
- **設定**: スコア重みの変更、サイドバー表示サイズの変更、JSON エクスポート/インポート、全データ削除
  - **JSONインポート**: 「JSONインポート」ボタンからバックアップJSON（`tus-class-helper-*.json`）を選ぶと既存データに上書きマージされます。**バックアップJSONを設定タブにドラッグ＆ドロップ**でも取り込めます
  - 読み込めない場合は、本拡張の「JSONエクスポート」で書き出したファイルか確認してください（破損・JSON形式でない場合は具体的なエラーメッセージが表示されます）

## LETUS：トップページ改造・To Do 連携・提出演出

LETUS（Moodle）のページを拡張します。トップページの改造、課題の To Do 連携、提出完了時の演出、
実績（XP・レベル・連続提出日数）をまとめて追加します。

### トップページ

**サイトニュースとマイコースの位置を丸ごと入れ替えます。** ページ全体の先頭にブロックを
移動することはしません（もとのあった位置同士を交換するだけです）。

| 機能 | 内容 |
|---|---|
| **反転（入れ替え）**（既定） | マイコース → サイトニュースがあった位置（メインカラム）／ サイトニュース → マイコースがいた位置（左サイドバー） |
| 配置モード 3 種 | `swap`（既定）/ `both-main` / `native` |
| 文字を大きく | 見出し・一覧の文字サイズを px 単位で自由設定（既定 26px / 22px） |
| アイコン変更 | LETUS が読み込んでいる **Font Awesome** の 84 アイコンから選択、またはクラス名を直接入力 |
| 色変更 | 見出し色・文字色・ホバー色・アクセント色・背景色、生の HEX / 8 桁 HEX に対応 |
| 並べ替え | マイコース内のコース一覧と、ブロックを **ドラッグ&ドロップ** または **▲▼** で自由に並べ替え。順序は `chrome.storage` に永続化 |
| **コースごとの個別設定** | 各コースの **⚙** から、そのコースだけの**文字色・アイコン・非表示**を設定（モーダルダイアログ） |
| **コースの非表示** | 一覧から隠して整理。非表示にしたコースは管理パネルから戻せます。順番は保持されるので、再表示しても元の位置に戻ります |
| **取り消し** | 非表示／再表示の直後に「元に戻す」トーストが出ます（6秒） |

#### 配置モード

| モード | 結果 |
|---|---|
| **`swap`（既定）** | **位置の交換。** マイコースがサイトニュースのあったメインカラム（画面中央）に入り、サイトニュースがマイコースのあった左サイドバーへ移動します |
| `both-main` | 両方メインカラム。マイコース → サイトニュース の順。2 ブロックの上下を入れ替え可能 |
| `native` | LETUS 元の配置に戻す |

##### サイドバーに移動したサイトニュース
サイドバーは幅が狭いため、**初期状態は折りたたまれています**（見出しをクリックで開閉）。
常に表示したい場合は 設定 →「3. サイトニュースの見た目」→ **「サイドバーでは折りたたむ」= 常に表示する**。

#### 操作方法

1. LETUS のトップページを開く。
2. ブロック上部の細いバー（`⠿ ▲▼ マイコース 並べ替え ⚙`）が現れる。
   - `⠿` … ドラッグハンドル（ブロックの並べ替え）
   - `▲▼` … 上下に動かす（`both-main` モードでブロックを入れ替える場合）
   - `並べ替え` … **コース一覧の操作列を表示／非表示** する切り替え
   - `⚙` … 設定ページを開く
3. **「並べ替え」を押すと**、各コースの左に `⠿ ▲▼ ⚙` が出ます。もう一度押すと消えます。

> 操作列は**並べ替えモードのときだけ**表示されます。通常は一覧を素のまま保つので、
> マウスを動かしただけでボタンが出たり、誤ってコースを隠したりすることがありません。

#### コースごとの ⚙ 設定

「並べ替え」モード中に各コースの **⚙** を押すと、モーダルダイアログが開きます。

- **文字色** … カラーピッカーで指定。「全体設定に戻す」で解除
- **アイコン** … Font Awesome の一覧から選択、またはクラス名を直接入力（プレビュー付き）
- **非表示** … 「このコースを一覧から隠す」
- **「このコースの設定を解除」** … 色・アイコンをまとめて解除（非表示状態は維持）

変更はその場で反映され、`chrome.storage` に保存されます。
色を指定した場合、カーソルを当てたときの色は**その色を自動で暗くした色**になります。

#### コースの非表示

- 非表示にする入口は **⚙ ダイアログのチェックボックスだけ**です（ワンクリックで消えるボタンはありません）
- 非表示にしたコースは一覧の下の **「非表示のコース（N）」** パネルに名前つきで並び、
  個別の **「表示に戻す」** または **「すべて表示する」** で復帰できます
- 非表示／復帰の直後は **「元に戻す」トースト**（6秒）が出るので、誤操作もすぐ取り消せます
- 例えば「卒業まで触らない科目（卒論・教職・情報倫理など）」を隠す用途に向いています

**実装上の注意**
- 非表示は inline style の `display:none` で制御しています（LETUS 側の CSS を上書きしないため）。
  `courseOrder` は**非表示のコースも含めて全件**を保持するので、再表示しても位置は変わりません
- ▲▼ とドラッグ&ドロップは**表示中の項目だけ**を対象にします（非表示のコースを飛び越えません）
- 交互の背景（縞）も表示中の項目だけを数えます
- 一覧から消えるだけで、LETUS 上のコース登録自体は変わりません（出席要件や採点には影響しません）

**2 つのブロックの順序を自由に切り替えたい場合は `both-main` モードを使ってください。**
設定を変えると**開いている LETUS のタブに即時反映**されます（再読み込み不要）。

##### 配置の安定性について
配置は「ブロックの元位置に置くアンカー要素」を基準に `insertBefore` だけで行うため、**冪等**です。
Moodle の YUI が `yui_*` の id を DOM に付けたり、`block_navigation` が非同期で描画したりして
MutationObserver が何度発火しても、配置は 1 回適用したときと同じ状態を保ちます。
（「ドラッグ後にマイコースがサイドバーの最下部へ移動してしまう」という症状の根本原因是、
`applyLayout()` がブロックの*現在位置*を参照していたことによる非冪等性でした。）

### 提出完了のパチンコ風演出

課題（出席チェックも Moodle の課題として作られているため同様）を **提出した瞬間** に、
パチンコの大当たり演出を全画面で表示します。

#### きっかけ（誤発火しない設計）

POST /mod/assign/view.php（提出フォーム） → 302 → GET /mod/assign/view.php?id=X&action=view

これに合わせて次の 3 段構えで検知します。

3. 印が取れなかった場合に備え、**提出ステータスが「未提出 → 提出済み」に変化した**ことでも検知

| # | フェーズ | 内容 |

| 0 | 入場 | 暗転 → 枠の電飾が**赤**く点灯、チャッカー入賞音 |

| 3 | 大当たり | 最後のみ が停止 → **「提出済み」が揃う**、**背景が七色に**（回転する放射状）、ストロボ全開（赤→金→虹）、**ドン**＋ファンファーレ、紙吹雪 |

**倍率との連動**

| 倍率 | 電飾の到達色 | リーチ回数 | 見せ方 |
|---|---|---|---|
| ×1 NICE | 赤 | 1 | 通常当たり |
| ×2 GREAT | 赤→金 | 1 | — |
| ×3 SUPER | 金 | 2 | リーチが長い |
| ×4 ULTRA | 金→虹 | 2 | — |
| ×5 LEGEND | 虹 | 3 | 「確変！」＋リール再変動 |

#### 演出の激しさ（off / 標準 / max）

設定 **`celebrate.intensity`** で、リール・紙吹雪・音量・追加演出をまとめて制御します。

| 要素 | off | 標準 | max（標準の約 2 倍） |
|---|---|---|---|
| リール回転 | 回さず即揃う | 1350 px/s | **2700 px/s** |
| リーチ回数 | 0（即大当たり） | 倍率どおり | **＋1 回** |
| 停止間隔 | 0 | 550ms | 380ms |
| 紙吹雪 | 0 | `confetti` 設定値 | **設定値×2** |
| 効果音の音量 | 0.35 | 0.5 | 0.62 |
| 追加演出 | なし | 通常 | 追加バースト＋追加ストロボ |

`off` では演出を最小限にしてすぐ結果へ進みます。
点滅（ストロボ）は `celebrate.strobe` で別に制御できるため、
「点滅だけ止める（strobe=off）」「全体を控えめにする（intensity=off）」を独立に選べます。

#### 当たりの背景（七色）

設定 **`celebrate.rainbow`** で、大当たり時の七色背景を段階で選べます。

| 段階 | 内容 |
|---|---|
| `off` | 出さない（暗い背景のまま） |
| `normal`（既定） | ゆっくり回転（約 9 秒/周）、不透明度 0.38 |
| `max` | **高速回転（約 3.2 秒/周）** ＋ **色相も回転** ＋ **逆回転する2枚目を重ねる** ＋ 不透明度 0.62 |

- `repeating-conic-gradient` の七色（赤→橙→黄→緑→シアン→青→紫）を放射状に敷き、回転させます
- **中心はマスク＋半透明のベールで暗く抜く**ため、パチンコ枠と結果テキストは読みやすいまま周囲が七色に輝きます
- 出現時はふわっとフェードインし、**明滅はしません**（点滅は `strobe` が担当するので安全）
- `prefers-reduced-motion` では回転を止めた静的な低不透明度表示になります
- 実装は **JS 駆動**（CSS アニメーションは環境によって止まることがあるため、以前の 3D テキストと同じ理由）

#### 光とストロボ（安全について）

電飾が 赤 → 金 → 虹 と段階的に変わり、大当たりではストロボが焚かれます。
全画面の強い点滅は**光過敏性発作**の誘因になり得るため（WCAG 2.3.1 は 1 秒 3 回超の点滅を禁止）、
設定 **`celebrate.strobe`** で強さを選べるようにしています。

| 値 | 内容 |
|---|---|
| `off` | 点滅しない（まぶしくない） |
| `weak` | 弱（低輝度・ゆっくり） |
| `normal`（既定） | 中 |
| `max` | 強（激しい点滅） |

ストロボは点滅のみを制御します（演出全体の激しさは `celebrate.intensity`）。

- OS の「視差効果を減らす」（`prefers-reduced-motion`）が有効なときは、**自動で `off`** になり、
  リールや 3D テキストも即座に最終状態へ切り替わります
- 体調に不安がある場合は設定を `off` にしてください

#### 演出のテスト表示

課題を実際に提出しなくても演出を確認できます。

- 設定ページ →「**7. 提出完了の演出**」→ **「演出をテスト表示」** ボタン
- もしくは `chrome-extension://<拡張機能ID>/letus/preview/preview.html` を直接開く

| 条件 | 内容 |

| レベル / レベルアップ | する / しない（LEVEL UP! 演出の有無） |
| 期限との関係 | 72時間以上前 / 24時間以上前 / ぎりぎり / 期限超過 / 期限なし |
| 集中した時間 | 分単位（0分も表示） |
| 課題名・コース名 | 任意 |

#### 効果音（合成音 / パチンコ向けに作り込み）

Web Audio で合成するため音声ファイルは不要です。パチンコらしさのために次を実装しています。

| 仕掛け | 内容 |
|---|---|
| **ホールの残響** | 合成したインパルス応答（0.9 秒）を `ConvolverNode` に通し、パチンコホールのような強い残響を付加（原音 0.85 ／ 残響 0.34） |
| **チャッカー入賞** | 非整数倍音（1 / 1.42 / 1.93 / 2.71 / 3.62 倍）を重ねた金属の短いリング＋ノイズの「チャッ」 |
| **保留ランプ点灯** | 2 音の電子音「ピポッ」（保留ごとに音程が少し上がる） |
| **リール変動** | 約 22〜42ms 間隔の**クリック連打**で「カラカラ」。止めるまで鳴り続ける |
| **リール停止** | 「カチッ」＋短い下降音 |
| **リーチ（キュイン）** | 高域を速く上下させるスイープ（980→3600→1150Hz）に**深いビブラート（30〜40Hz）**を掛けた「キュイン」。リーチ回数に応じて 2〜3 連 |
| **大当たり（ドン）** | 低音の衝撃（165→36Hz）＋低域ノイズ |
| **大当たりファンファーレ** | チャージの上昇スイープ → 速い上行フレーズ（ピコピコ）→ 締めの和音＋クラッシュ → **出玉の「チャリンチャリン」**（金属音を不規則間隔で連打）→ 余韻のフィーバーループ |
| **確変の警告音** | ビブラート付きの警告音（×5 LEGEND のとき） |
| **XP カウント／レベルアップ** | 拍動クリック音／上昇スイープ＋チャイム |

演出の激しさ（`celebrate.intensity`）に応じて**音量**（0.35 / 0.5 / 0.62）と
リール回転音のテンポも変わります。

> ⚠ **既知の制約**: 演出はページ遷移の直後に出るため、Chrome の自動再生ポリシーで
> `AudioContext` が一時停止したままのことがあります。その場合は**無音で続行**し、
> 演出内に「🔊 クリックで音を有効にする」を表示します（押すと鳴り、以降は鳴りやすくなります）。
> テスト表示ページはクリック直後に再生するため音を確認しやすいです。

#### XP・レベル・連続提出日数

提出のたびに加算して `chrome.storage.local` に保存します。

| 項目 | 計算 |
|---|---|
| 基本 | +150（提出） |
| 期限内 | +100 |
| 早期ボーナス | 期限の 72 時間以上前 +100 ／ 24 時間以上前 +50（排他） |
| 倍率 | 連続提出日数に応じて ×1〜×5 |

| 連続日数 | 倍率 | ティア |
|---|---|---|
| 1 | ×1 | NICE |
| 2 | ×2 | GREAT |
| 3–4 | ×3 | SUPER |
| 5–6 | ×4 | ULTRA |
| 7+ | ×5 | LEGEND |

- 連続日数は **提出した日（既定 `Asia/Tokyo`）が連続するか**で数えます。同じ日に 2 回提出しても据え置き、1 日空くと 1 に戻ります
- レベルは `xpForLevel(L) = 300(L−1) + 60(L−1)²`。称号は Lv 帯で決まります

実績は **設定ページの「9. 実績」** と **ツールバーのポップアップ** で確認できます（履歴10件つき）。

## ダークモード

CLASS・LETUS・拡張の画面を暗くします。操作は **ツールバーのポップアップだけ**（設定ページはありません）。

### 使い方

ポップアップ下部の「ダークモード」で次を切り替えます。

| 項目 | 選択肢 |
|---|---|
| **切替** | オフ ／ 常に暗く ／ 自動（下の自動切替に従う） |
| **自動切替** | 時刻指定（開始〜終了、終了が開始より前なら翌日扱い） ／ 日の出〜日の入り ／ OS の設定 |
| **対象** | CLASS ／ LETUS ／ 拡張の画面（ポップアップ・ダッシュボード・設定・演出テスト）を個別に ON/OFF |

「次に切り替わる予定」のヒントが表示され、保存は即時・対象タブへ反映されます。

- **日の出・日の入**は固定座標（東京 緯度 35.70 / 経度 139.74）で計算しています。座標の入力 UI はありません
- 時刻指定で終了時刻が開始時刻より前（例 19:00 → 06:00）の場合は **日をまたいで暗くなります**
- 切替の判定は `chrome.storage.local` の `tusTheme` キー（既定 `mode: "off"`）で行います

### 仕組み（ホストページ側）

クラス・LETUS のページは **反転方式** です（サイト側の CSS を書き換えません）。

- `html` の上に `backdrop-filter: invert(1) hue-rotate(180deg)` の **透過オーバーレイ**を常時置き、ページ全体を反転します
- その上に拡張が置いた UI（シラバス比較ボタン・スロットバー・サイドバー・トーストなど）は **再反転** して元の配色のまま表示します（ホストページの z-index 9999999 に対し当拡張は 2147483000〜）
- 写真・動画・アイコン・キャプチャ用 canvas は再反転して元の色に戻します
- 反転で黒くなる白背景を防ぐため、ダーク時のみ `html` の背景を白にしておきます
- `color-scheme: dark` は **ホストページでは使いません**（UA のフォーム部品が反転されて明るく浮くため）。拡張ページ側でのみ使用します

### 制限

- 網掛け・透過 PNG など、反転すると色が変わる素材は完全には再現できません
- サイト側が追加した要素やサービス内蔵のポップアップも一括で反転されます（拡張側の再反転対象外）

## To Do 連携のセットアップ（要 1 回だけ）

**必要な権限はオプション権限です。** 設定ページの「5. To Do 連携の許可」で「**To Do 連携を有効にする**」を押すか、
課題ページの「To Do に追加」ボタンを初めて押したときに許可を求められます。
許可しない場合、ボタンには案内が表示され、それ以外の機能は通常どおり動きます。

### Google Tasks のセットアップ

Google Tasks には「タスク追加用 URL スキーム」が存在しないため、**Tasks API + OAuth** を使います。
初回だけログイン許可画面が表示され、以降はボタン押すだけで期限入りのタスクが作成されます。

1. [Google Cloud API ライブラリ](https://console.cloud.google.com/apis/library/tasks.googleapis.com) を開き、**Google Tasks API** を有効化。
2. [OAuth 同意画面](https://console.cloud.google.com/apis/credentials/consent) を設定。
   - ユーザータイプ: 外部
   - アプリの公開ステータス: **テスト**
   - テストユーザーに自分の Google アカウントを追加
3. [認証情報](https://console.cloud.google.com/apis/credentials) → **OAuth クライアントIDを作成**
   - アプリケーションの種類: **Chrome 拡張機能**
   - クライアントIDをコピー
4. `manifest.json` の `oauth2.client_id` を貼り替える。

```jsonc
"oauth2": {
  "client_id": "xxxxxxxx.apps.googleusercontent.com",   // ← ここを自分の ID に
  "scopes": ["https://www.googleapis.com/auth/tasks"]
}
```

5. `chrome://extensions` で拡張機能を再読み込み（⟳）。

これで完了。課題ページのボタンを押すと Google のログイン画面が 1 回開き、以降は自動で追加されます。
トークンの更新は Chrome が行うので、拡張機能側で再ログインを求められることはありません。

### Microsoft To Do のセットアップ

Microsoft To Do も「期限込みでタスクを作れる URL スキーム」が公開されていないため、**Microsoft Graph API + OAuth（PKCE）** を使います。

1. [Microsoft Entra 管理センター](https://entra.microsoft.com/) → **アプリ登録** → **新しい登録**
   - 名前: `LETUS Assist` など
   - サポートアカウント: 個人利用なら **個人用 Microsoft アカウントのみ**（設定は `consumers`）／ 学校アカウントも使うなら **任意の組織・アカウントディレクトリ以上のアカウント**（設定は `common`）
2. **認証情報** を開く。下にある「設定」ページの「Microsoft To Do 連携」欄に表示されている
   `https://<拡張機能ID>.chromiumapp.org/` を
   **リダイレクト URI（SPI）** に追加して保存。
   拡張機能 ID は `chrome://extensions` の拡張機能詳細ページで確認できます。
   （ platforms は **シングルページアプリケーション (SPA)** を選びます。クライアントシークレットは不要）
3. 「アプリケーション (クライアント) ID」を拡張機能の設定ページへ貼り付け、**接続** を押す。
4. Microsoft アカウントでサインインして許可。接続済みのリストを **接続テスト** で確認できます。

補足:
- 追加先のリスト名は既定で `Tasks`（To Do の「タスク」）。別のリストにしたい場合は設定で指定します。
- リマインダーは既定で期限 1 時間前。時刻は Graph が `timeZone: "UTC"` で受け取ります。
- Microsoft To Do 自体が残り時間を「日単位」で丸めるため、時刻は To Do アプリ側の表示に従います。

## 注意事項

- 公式の学務システムへの変更でセレクタが壊れる可能性あり
- 成績データの二次配布は不可。本拡張は個人の履修検討用途
- 認証セッションが切れるとCLASS側の操作は不可だが、拡張に保存したデータは残る

  体調に不安がある場合は `off` にしてください（OS の「視差効果を減らす」が有効なら自動で停止します）

## 動作検証済みの環境

Playwright + Chromium で、保存済み HTML（`LETUS2026.html` / `微分積分２.html`）に
**LETUS 本体の CSS も読み込ませた状態**で実機検証しています。

- 反転（`swap`）が「位置の交換」になっていることを実測：マイコースが `yui…`（メインカラム）内、
  サイトニュースが `block-region-side-pre` 内で **かつ マイコースの元の位置（オンラインユーザの直後・inst2 の直前）** にあること、
  そして `#page-content` の先頭に何も挿入されていないこと
- **冪等性**: `applyLayout()` を 5 回連続適用しても DOM シリアライズが完全に一致すること
- **MutationObserver 連打耐性**: 60 回の連続 DOM 操作、ドラッグ中の DOM 操作、`yui_*` id の連続付与の後も配置が保たれること
- **ドラッグ回帰**: コースをドラッグ並べ替え → リロード後も ①マイコースがメインカラム ②検索欄が元の位置 ③ニュースがサイドバーの元位置
- **非表示機能（27 項目）**: 1/4/全件の非表示、storage への保存、リロード後の維持、パネルからの個別復帰と一括復帰、
  非表示のコースも `courseOrder` に含まれること、非表示がある状態での並べ替え（表示中の項目だけを移動）・
  縞の連番が崩れないこと、
  設定ページとの双方向即時反映
- 保存済み HTML（`letus_assist_ref/saved_pages/swap_build.html` = 旧コードで壊れた状態）に同じ検査をかけると**確実に不合格**になることを確認
  （テストが空振りしていないことの検証）
- サイトニュースの折りたたみ（初期状態で閉じ、クリックで開閉）
- 設定変更が開いているタブへ即時反映されること
- 既定の文字サイズ・色・アイコン・アクセント色・2 段組の反映
- `hero` モードの削除、旧設定の `swap` への自動移行
- ドラッグ&ドロップ、▲▼、並べ替えモードの表示切替
- 順序の保存とリロード後の復元（コース一覧・ブロック両方）
- 提出ステータス直下への挿入、期限パース、タスク名生成、SW 往復
- Google Tasks / Microsoft Graph のリクエスト内容（URL・メソッド・ボディ・RFC3339 変換・トークン更新・リマインダー時刻）
- 設定ページの自動保存とページへの反映
- **パチンコ演出（追加検証）**: 保留ランプの点灯、リール4つが「提・出・済・み」で揃い LETUS 緑（`#cfefcf`）になること、
  大当たりフラグ・テロップ・3D「課題提出」の表示、倍率ごとの電飾色（赤/金/虹）とリーチ回数、
  ストロボ `off` で点滅要素が出ないこと、スキップで結果へ飛ぶこと
