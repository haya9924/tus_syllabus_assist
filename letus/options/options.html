LETUS(Moodle) トップページのカスタマイズと、課題の To Do 追加設定

1. トップページの配置

「入れ替え」では、マイコースがサイトニュースがあった位置（メインカラム）へ、 サイトニュースがマイコースがいた位置（左サイドバー）へ 移動します。ページ全体の先頭に移動することはありません。

実際の並べ替えはページ上の「⠿」ドラッグ、または各ブロックの「並べ替え」ボタン（▲▼）で行えます。順序は保存されます。

2. マイコースの見た目

一覧の各項目にカーソルを合わせると ⠿ ▲▼ ● が表示されます。 ● を押すとそのコースを一覧から隠します（非表示にした courses は下の「非表示のコース」から戻せます）。

2-2. コースごとの個別設定

LETUS のトップページで「並べ替え」を押すと、各コースの左に ⠿ ▲▼ ⚙ が出ます。 ⚙ から、そのコースだけの文字色・アイコン・非表示を設定できます。

5. To Do 連携の許可

確認中…

Google Tasks / Microsoft To Do への追加には、認証（identity）と各サービスの通信先へのアクセス許可が必要です。 使い始めるときに一度だけ許可を求めます。この拡張機能の他の機能（CLASS・LETUS の改造・演出）は許可なしで動きます。

6. Google Tasks 連携

確認中…

  1. Google Cloud の API ライブラリ で Google Tasks API を有効化する。
  2. 同じ画面で OAuth 同意画面 を設定し、アプリの公開ステータスを「テスト」、テストユーザーに自分の Google アカウントを追加する。
  3. 認証情報 → OAuth クライアントIDを作成 → アプリケーションの種類は Chrome 拡張機能 を選ぶ。
  4. 作成したクライアントIDを manifest.json の oauth2.client_id に貼り付け、拡張機能を再読み込みする。

7. Microsoft To Do 連携

確認中…

  1. Microsoft Entra 管理センター → アプリ登録 → 新しい登録。
  2. 認証設定で プラットフォーム: シングルページアプリケーション (SPA)、リダイレクト URI に を追加して保存する。
  3. 下にある「クライアントID」を貼り付けて 接続 を押す。

8. 提出完了の演出

課題（出席チェック含む）を提出した直後に「SUPER COMPLETE!!」の演出を表示します。 提出ボタン（id_submitbutton）を押した時だけ発火し、下書き保存では出ません。

課題を実際に提出しなくても演出を確認できます。条件（倍率・レベルアップ・紙吹雪の量など）を 変えて試せる専用ページが開きます。実績は変化しません。

音はページ遷移直後のため、Chrome の自動再生ポリシーでブロックされることがあります。 その場合は演出内の「🔊 クリックで音を有効にする」を一度押すと鳴ります。

⚠ 「ストロボの強さ」を上げると画面が激しく点滅します。光過敏性発作などのおそれがあるため、 体調に不安がある場合は「なし」にしてください。OS の「視差効果を減らす」が有効なときは自動で点滅しません。
